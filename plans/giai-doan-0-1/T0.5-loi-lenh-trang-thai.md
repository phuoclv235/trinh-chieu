## 1. Mô hình tài liệu

Theo **đúng** `docs/dinh-dang-tep.md` mục 2 đến 4 và 8. Yêu cầu:

- Mọi kiểu là `struct` (`enum` cho kiểu tổng), `Codable`, `Sendable`, `Hashable`.
- Tên trường Swift trùng tên khoá JSON. `Element` mã hoá với khoá phân biệt `"type"`; `ServicePlanItem` cũng vậy.
- `RGBA` mã hoá thành chuỗi `#RRGGBBAA`; giải mã chấp nhận `#RRGGBB` (alpha FF) và `#RRGGBBAA`, không phân biệt hoa thường; chuỗi sai thì ném lỗi có thông điệp tiếng Việt.
- `frame` mã hoá thành mảng 4 số `[x, y, w, h]`; `canvasSize` thành `[w, h]`.
- `TextStyle` có hai dạng: `TextStyle` (đủ trường, không optional, dùng trong `Theme`) và `TextStyleOverride` (mọi trường optional, dùng trong `Element`). Có hàm `TextStyle.applying(_ override: TextStyleOverride) -> TextStyle`.
- `Presentation.orderedGroups() -> [SlideGroup]` trả các đoạn theo thứ tự hát đang chọn (hoặc thứ tự gốc khi không có), bỏ qua `groupIDs` không tồn tại.
- `DocumentCoding`: `JSONEncoder` với `.prettyPrinted, .sortedKeys, .withoutEscapingSlashes`, ngày ISO 8601; `JSONDecoder` tương ứng. Mọi nơi đọc ghi tài liệu dùng hai đối tượng này.
- `Migration`: hàm `func migrate(_ data: Data, kind: DocumentKind) throws -> (Data, migratedFrom: Int?)`. Ở schema 1 chỉ kiểm `schemaVersion` (thiếu thì coi là 1; lớn hơn phiên bản hiện tại thì ném lỗi "Tệp được tạo bởi phiên bản Hệ thống mới hơn"). Khung để sẵn cho các bước `v1 → v2` về sau.

Giá trị mặc định khi tạo mới: `Presentation.newSong(title:)` tạo một đoạn `verse 1` rỗng có một trang với một phần tử chữ `slot = body`, một thứ tự hát "Mặc định".

## 2. Lệnh (`ShowCommand`)

```swift
public enum ShowCommand: Sendable, Equatable, Codable {
    case loadPlan(planID: UUID?)                    // nil = không dùng chương trình
    case selectItem(LiveSource)                     // hiện lưới trang của nguồn, không lên màn
    case goLive(LiveSource, slideIndex: Int)        // chỉ số trong SlideSequence của nguồn
    case next
    case previous
    case clearLayer(LayerKind)
    case clearAll
    case setFreeze(Bool)
    case setRehearsal(Bool)
    case contentDidChange(ids: Set<UUID>)           // thư viện báo nội dung đổi; dựng lại cảnh nếu đang chiếu nội dung đó
}

public enum LiveSource: Sendable, Hashable, Codable {
    case planItem(planID: UUID, itemID: UUID)
    case presentation(id: UUID, arrangementID: UUID?)
    case scripture(translation: String, reference: String)   // chuỗi địa chỉ đã chuẩn hoá bởi Scripture
    case media(MediaID)
}
```

Mã hoá JSON có khoá phân biệt `"type"` bằng đúng tên case (`"goLive"`, `"clearLayer"`...). Đây là hợp đồng cho remote và nhật ký: có test so khớp chuỗi JSON cố định cho từng case.

## 3. Nguồn nội dung và chuỗi trang

```swift
@MainActor public protocol ShowContentProvider: AnyObject {
    func plan(_ id: UUID) -> ServicePlan?
    func sequence(for source: LiveSource) -> SlideSequence?     // nil = không tìm thấy hoặc không chiếu được
    func theme(_ id: UUID?) -> Theme                            // nil hoặc không tìm thấy = mẫu mặc định của thư viện
    func mediaURL(_ id: MediaID) -> URL?                        // nil = media không còn trên đĩa
}

public struct SlideSequence: Sendable, Equatable {
    public var source: LiveSource
    public var title: String
    public var themeID: UUID?                     // mẫu đã giải theo ưu tiên: mục chương trình > bộ trình chiếu > mặc định thư viện
    public var slides: [SequencedSlide]
}

public struct SequencedSlide: Sendable, Equatable {
    public var slide: Slide
    public var groupID: UUID?
    public var groupLabel: GroupLabel?
    public var indexInGroup: Int
    public var presentationID: UUID?
}
```

Nhà cung cấp chạy đồng bộ trên luồng chính: thư viện giữ toàn bộ tài liệu JSON trong bộ nhớ (T1.3) và tra Kinh Thánh SQLite dưới 1 ms (T1.2). Trong T0.5 viết `InMemoryContentProvider` cho test.

`media` tạo một chuỗi một trang có nền là media đó. Mục `header` và `note` trả `nil` (không lên màn được).

## 5. Bộ điều khiển (`ShowController`)

```swift
@MainActor @Observable public final class ShowController {
    public private(set) var state: ShowState
    public init(provider: any ShowContentProvider, sink: any SceneSink, resolver: any SceneResolving,
                log: any ServiceLogSink, clock: any ShowClock)
    @discardableResult public func send(_ command: ShowCommand) -> CommandResult
}

public enum CommandResult: Sendable, Equatable { case applied, ignored(IgnoreReason) }
public enum IgnoreReason: Sendable, Equatable { case notFound, notLiveable, atEnd, atStart, frozen, nothingLive }
```

Quy tắc xử lý (mỗi quy tắc một test):

1. `goLive(source, i)`: lấy chuỗi; không có thì `ignored(.notFound)`; chỉ số ngoài phạm vi thì `ignored(.notFound)`. Trang `enabled == false` vẫn lên được khi chọn trực tiếp. Đặt `live`, đặt lớp `slide`; nếu trang có nền riêng (`background.kind != none`) thì thay lớp `background`, nếu không thì giữ nền đang có, và nếu lớp nền đang trống thì dùng nền của mẫu. Ghi nhật ký `goLive`.
2. `next`: không có `live` thì `ignored(.nothingLive)`. Tìm trang kế có `enabled`. Hết trang: nếu `advanceToNextItem` và nguồn là `planItem` thì lên trang đầu tiên của mục kế tiếp lên màn được (bỏ qua `header`, `note`, mục không tìm thấy); nếu không thì `ignored(.atEnd)`.
3. `previous`: trang trước có `enabled`; ở trang đầu thì `ignored(.atStart)`. **Không** lùi sang mục trước.
4. `clearLayer(.slide)`: bỏ `live` và lớp `slide`. `clearLayer(.background)`: bỏ lớp nền. `clearAll`: bỏ mọi lớp và `live`.
5. `setFreeze(true)`: trạng thái vẫn đổi theo lệnh, nhưng không xuất cảnh mới ra đầu ra (xem mục 6). Tắt đóng băng thì xuất ngay cảnh hiện tại.
6. `setRehearsal(true)`: như đóng băng với đầu ra chính, nhưng xem trước vẫn cập nhật. Khác đóng băng ở chỗ ý nghĩa với người dùng và màu cảnh báo trên giao diện.
7. `contentDidChange(ids)`: nếu nội dung đang chiếu nằm trong `ids` thì lấy lại chuỗi; trang đang chiếu tìm theo `slideID`, mất thì giữ chỉ số nếu còn hợp lệ, không thì xoá lớp chữ. Dựng lại cảnh.
8. `selectItem`: chỉ đổi `selected`. `loadPlan`: đổi `activePlanID`, `selected = nil`, không đụng đầu ra.

Sau mỗi lệnh `applied`, controller gọi `resolver` dựng cảnh rồi giao cho `sink` theo mục 6. Lệnh `ignored` không gọi `sink`.

`ShowClock` là giao thức cho thời gian (`now`, và một lần đếm nhịp mỗi giây để màn hình nhắc cập nhật đồng hồ). Test dùng đồng hồ giả.

## 6. Xuất cảnh (`SceneSink`, `SceneResolving`)

```swift
public protocol SceneResolving: Sendable {
    @MainActor func resolve(state: ShowState, provider: any ShowContentProvider, now: Date) -> ScenePublication
}

public struct ScenePublication: Sendable, Equatable {
    public var program: RenderScene     // đầu ra chính
    public var stage: RenderScene       // màn hình nhắc
}

@MainActor public protocol SceneSink: AnyObject {
    func publishToOutputs(_ publication: ScenePublication)
    func publishToPreview(_ publication: ScenePublication)
}
```

- Bình thường: gọi cả `publishToOutputs` và `publishToPreview`.
- Đóng băng: chỉ `publishToPreview`. Màn hình nhắc **vẫn** cập nhật khi đóng băng (người trên bục cần biết trang kế), nghĩa là `publishToOutputs` được gọi với `program` của lần xuất cuối trước khi đóng băng và `stage` mới. Controller giữ `lastProgramPublished` để làm việc này.
- Tập dượt: giống đóng băng.
- Mỗi giây, controller dựng lại cảnh để cập nhật đồng hồ và chỉ gọi khi `stage` khác lần trước.

T0.5 chỉ viết `SceneResolving` giả cho test. `SceneResolver` thật làm ở T1.5.

## 8. Soạn và hoàn tác (`DocumentEditor`)

```swift
@MainActor @Observable public final class DocumentEditor<Doc: Equatable & Sendable> {
    public private(set) var document: Doc
    public func apply(_ change: (inout Doc) -> Void, actionName: String, coalescingKey: String? = nil)
    public func undo(); public func redo()
    public var canUndo: Bool; public var canRedo: Bool
    public var undoActionName: String?; public var redoActionName: String?
    public var onChange: ((Doc) -> Void)?   // LibraryStore gắn vào để lưu có hoãn
}
```

Hoàn tác theo ảnh chụp giá trị (lưu bản `Doc` trước khi đổi). Hai lần `apply` liên tiếp cùng `coalescingKey` trong vòng 1 giây gộp thành một bước (gõ chữ). Giữ tối đa 200 bước.
